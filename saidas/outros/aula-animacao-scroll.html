TÉCNICA 01

Revelar ao entrar na tela

A mais usada de todas. O elemento começa invisível e um pouco abaixo. Quando ele aparece na tela, o JavaScript coloca uma classe nele e o CSS faz a transição.

Funciona em qualquer site, sem biblioteca nenhuma. A animação dispara uma vez e roda sozinha, não importa a velocidade que você rola.

Quando usar: títulos, cards de produto, depoimentos. Quase todo site "bonito" tem isso.

/* CSS: começa escondido e abaixo */
.revelar {
  opacity: 0;
  transform: translateY(48px);
  transition: .9s;
}
.revelar.visivel {
  opacity: 1;
  transform: none;
}

// JS: um "olho" que avisa quando entra na tela
const olho = new IntersectionObserver((itens) => {
  itens.forEach((item) => {
    if (item.isIntersecting)
      item.target.classList.add('visivel');
  });
}, { threshold: 0.2 }); // 20% visível = dispara

document.querySelectorAll('.revelar')
  .forEach((el) => olho.observe(el));

TÉCNICA 02

Parallax

Várias camadas andando em velocidades diferentes enquanto você rola. O cérebro lê isso como profundidade, igual olhar pela janela do carro: o que tá longe anda devagar, o que tá perto passa rápido.

Aqui entra o GSAP + ScrollTrigger, a biblioteca que quase todo site premiado usa. A diferença pra técnica 1: com scrub a animação segue o seu dedo. Rolou metade, ela tá na metade. Parou, ela para.

Quando usar: topo do site, fundo de seções, fotos grandes.

<!-- HTML: cada camada diz sua velocidade -->
<div data-velocidade="-0.6">OUD</div>  <!-- longe -->
<div data-velocidade="0.3">frasco</div>
<div data-velocidade="1.2">brilhos</div> <!-- perto -->

// JS: pra cada camada...
gsap.fromTo(camada,
  { y: velocidade * 250 },   // sai daqui
  { y: velocidade * -250,    // chega aqui
    ease: 'none',
    scrollTrigger: {
      trigger: '#t2',
      start: 'top bottom', // seção apareceu
      end: 'bottom top',   // seção saiu
      scrub: true          // segue o dedo
    }
  });

TÉCNICA 03

A seção que "gruda" na tela

Esse é o efeito estilo Apple, o que mais aparece nesses vídeos. A seção fica presa (pin) e, em vez da página descer, o seu scroll vira o controle de um filme: o frasco cresce, enche, abre a tampa e o texto vai trocando.

O segredo é a timeline: uma fila de animações, uma depois da outra. O scroll só decide em que ponto do filme você está. Repara no contador de % no canto da seção.

Quando usar: apresentar UM produto principal, contar uma história em etapas. 1 ou 2 por site, no máximo.

const filme = gsap.timeline({
  scrollTrigger: {
    trigger: '#t3',
    start: 'top top',
    end: '+=300%', // dura 3 telas de rolagem
    pin: true,     // a seção fica PARADA
    scrub: 1       // segue o scroll (1s de suavidade)
  }
});

// as cenas, em ordem:
filme
  .from('.frasco',  { scale: 0.5, rotate: -25 })
  .from('.liquido', { scaleY: 0 })   // enche
  .to('.nota-1',    { opacity: 1 })  // texto 1
  .to('.nota-1',    { opacity: 0 })
  .to('.nota-2',    { opacity: 1 })  // texto 2
  // ...
  .to('.tampa',     { y: -60 });     // abre

TÉCNICA 04

Rolagem horizontal

Você rola pra baixo, os cards andam pro lado. É a técnica 3 de novo (seção presa + scrub), só que a animação é mover a fileira inteira pra esquerda.

A conta é simples: a fileira anda o quanto ela é maior que a tela, e a seção fica presa por essa mesma distância de rolagem.

Quando usar: vitrine de produtos, portfólio, linha do tempo.

const trilho = document.querySelector('.trilho');
// quanto a fileira passa da largura da tela
const sobra = () =>
  trilho.scrollWidth - window.innerWidth;

gsap.to(trilho, {
  x: () => -sobra(),       // anda pra esquerda
  ease: 'none',
  scrollTrigger: {
    trigger: '#t4',
    start: 'top top',
    end: () => '+=' + sobra(), // mesma distância
    pin: true,
    scrub: 1
  }
});

TÉCNICA 05

Texto que acende palavra por palavra

Muito comum nesses vídeos. O truque: quebrar a frase em palavras, cada uma dentro de um <span> quase transparente, e acender uma de cada vez com stagger (escalonado) amarrado ao scroll.

Quando usar: a frase de impacto da marca, o "sobre nós", uma citação.

// 1. quebra a frase: cada palavra vira um <span>
const frase = document.querySelector('.acender');
frase.innerHTML = frase.textContent
  .split(' ')
  .map((p) => `<span class="palavra">${p}</span>`)
  .join(' ');

// 2. acende uma depois da outra
gsap.to('.palavra', {
  opacity: 1,
  stagger: 0.1,   // uma de cada vez
  scrollTrigger: {
    trigger: '.acender',
    start: 'top 80%',
    end: 'bottom 40%',
    scrub: true
  }
});

Um perfume não é só cheiro. É a lembrança que fica no ar depois que você sai da sala.

RESUMO

Toda animação de scroll responde 3 perguntas

1

Quando começa e termina?

É o gatilho: start e end. 'top 80%' quer dizer "quando o topo do elemento chegar a 80% da altura da tela". Aperte Ver gatilhos lá embaixo pra ver as linhas.

2

O que muda?

Posição (x, y), tamanho (scale), giro (rotate) e transparência (opacity). Só essas quatro rodam lisinho no celular.

3

Dispara sozinha ou segue o dedo?

Dispara: entrou na tela, roda inteira (técnica 1). Segue o dedo (scrub): o scroll controla o andamento (técnicas 2 a 5).

As ferramentas

  • GSAP + ScrollTrigger: o padrão do mercado, de graça desde 2025. Funciona em qualquer site, inclusive nos seus em Next.js. É o que essa página usa.
  • Lenis: deixa a rolagem "amanteigada", aquele deslizar macio dos sites premiados. Desliga no botão Rolagem suave pra sentir a diferença.
  • CSS puro (animation-timeline): sem biblioteca nenhuma. A barra dourada no topo da página é feita assim. Ainda não funciona em todos os navegadores.
  • Motion (antigo Framer Motion): o jeito "React" de fazer, encaixa bem em Next.js.

Pra treinar

  • 1. No CSS, procure EXERCÍCIO 1 e troque translateY(48px) por translateX(-80px). Os cards passam a entrar pelo lado.
  • 2. No JS, procure EXERCÍCIO 2 e troque '+=300%' por '+=100%'. O "filme" do frasco fica 3x mais rápido.
  • 3. No EXERCÍCIO 3, troque scrub: 1 por scrub: true e depois por scrub: 3. Repare no "atraso" macio.
  • 4. Aperte Ver gatilhos e role a página olhando onde start encontra scroller-start.
BÔNUS

A barra lá em cima

Só CSS. Em vez do tempo (segundos), a animação usa o scroll como relógio. Página no começo = barra vazia, página no fim = barra cheia.

.progresso {
  position: fixed;
  top: 0; left: 0; right: 0;
  height: 4px;
  transform-origin: left;
  animation: encher linear;
  animation-timeline: scroll(); /* o "relógio" é o scroll */
}
@keyframes encher {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}
